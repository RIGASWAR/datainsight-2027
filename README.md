## 🏛️ Host Institution & Event Overview

- **Host**: Department of Information Technology, **PSG College of Technology**
- **Location**: Peelamedu, Coimbatore – 641004, Tamil Nadu, India
- **Dates**: **December 16–18, 2027**
- **Live Website**: [https://datainsight-2027.vercel.app](https://datainsight-2027.vercel.app)

**DATAINSIGHT 2027** brings together leading global researchers, engineers, practitioners, and academicians across computer vision, speech analytics, multimodal deep learning, cybersecurity, and trustworthy artificial intelligence to share groundbreaking research and discuss the future of secure data intelligence.

## ✨ Features & Architecture

- **Smooth Scroll Transition System**: Built with Framer Motion, featuring progressive section entrance animations, subtle hero parallax, and fluid interactive timeline milestones.
- **Micro-Interactions**: Hover elevation, subtle glow amplification, dynamic track accordions with height animation, and a responsive back-to-top button.
- **Scrollspy Navigation**: Glassmorphic sticky header with active section highlight underline and responsive drawer navigation.
- **Live Countdown**: Precision countdown timer targeting December 16, 2027 with dynamic state transition.
- **Zero-Latency Edge Deployment**: Deployed on Vercel's Global Edge Network with HTTP/3, Brotli compression, and immutable asset caching.
- **Full Accessibility**: Built-in `prefers-reduced-motion` support across all components.

## 🚀 Local Development

```bash
# Clone repository
git clone https://github.com/RIGASWAR/datainsight-2027.git
cd datainsight-2027

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
